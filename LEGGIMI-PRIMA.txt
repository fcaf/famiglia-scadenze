AGGIORNAMENTO — Attività e Scadenze di famiglia
================================================

Questa cartella contiene SOLO i file cambiati. Volutamente NON contiene js/config.js,
così i valori che hai già inserito restano quelli che hai configurato.

Come applicarlo su GitHub (dal browser):

1. Apri il tuo repository → pulsante "Add file" → "Upload files".
2. Trascina nella pagina questi elementi presi da dentro questa cartella:
      index.html
      sw.js
      .nojekyll
      README.md
      la cartella  js   (contiene app.js e le due librerie)
   NON trascinare l'intera cartella "aggiornamento": trascina il suo CONTENUTO,
   altrimenti i file finiscono dentro una sottocartella e il sito non parte.
3. Scrivi un messaggio qualsiasi (es. "aggiornamento") e premi "Commit changes".
4. GitHub sovrascrive solo i file che hai caricato: js/config.js resta intatto.
5. Attendi 1-2 minuti (pallino giallo → verde in alto nel repository), poi apri il sito
   e ricarica con Ctrl+F5 (sul telefono: chiudi e riapri l'app).

Se il file .nojekyll non si vede quando lo trascini, è perché inizia con un punto e il
sistema lo considera nascosto: su Windows attiva "Elementi nascosti" nella scheda
Visualizza di Esplora file, oppure crealo direttamente su GitHub con
"Add file → Create new file", nome  .nojekyll  e contenuto vuoto.

Da questa versione l'app non resta mai bianca: se qualcosa non va, lo scrive sullo schermo.
