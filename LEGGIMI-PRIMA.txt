STRUTTURA PIATTA — Attività e Scadenze di famiglia
==================================================

Perché questa versione
----------------------
Caricando i file su GitHub con il trascinamento, le cartelle si perdono se non si
trascinano le cartelle stesse: i file finiscono tutti nella radice e l'app non trova
più niente (pagina bianca). Questa versione è fatta apposta per stare tutta su un
livello solo: nessuna cartella da ricostruire.

Che cosa caricare
-----------------
1. Apri il tuo repository su GitHub → "Add file" → "Upload files".
2. Apri questa cartella, seleziona TUTTI i file (Ctrl+A) e trascinali nella pagina.
   Va benissimo che sovrascrivano quelli già presenti.
3. Scrivi un messaggio (es. "struttura piatta") e premi "Commit changes".

ATTENZIONE a config.js
----------------------
In questa cartella NON c'è config.js, perché il tuo contiene già i valori giusti e
non va sovrascritto. Se però lo avessi perso, ricrealo con "Add file → Create new
file", nome  config.js , e questo contenuto (sostituendo i tre valori):

  window.CONFIG = {
    SUPABASE_URL:  "https://TUO-PROGETTO.supabase.co",
    SUPABASE_ANON: "LA-TUA-CHIAVE-ANON",
    VAPID_PUBLIC:  "",
    NOTA_ACCESSO:  "Gli account vengono creati dall'amministratore di famiglia."
  };

Il promemoria giornaliero (si fa una volta sola)
------------------------------------------------
Il file promemoria.yml è l'unico che DEVE stare in una cartella precisa. Su GitHub:
  "Add file" → "Create new file"
  nel campo del nome scrivi esattamente:   .github/workflows/promemoria.yml
  (scrivendo le barre, GitHub crea le cartelle da solo)
  poi apri promemoria.yml di questa cartella, copia tutto il contenuto, incollalo
  nella pagina e premi "Commit changes".
Il promemoria.yml che hai adesso nella radice non serve a niente: puoi cancellarlo.

File da cancellare (facoltativo, solo per ordine)
-------------------------------------------------
Se nella radice ci sono rimasti doppioni o file inutili (per esempio una cartella
"download" o un vecchio LEGGIMI), puoi cancellarli: aprili e usa l'icona del cestino.
Non cancellare mai: index.html, config.js, app.js, stile.css, supabase.min.js,
591.supabase.js, xlsx.full.min.js, sw.js, manifest.webmanifest, le tre icone.

Dopo il caricamento
-------------------
Aspetta che il pallino in alto nel repository diventi verde (1-2 minuti), poi apri il
sito e ricarica con Ctrl+F5. Se qualcosa non va, l'app non resta bianca: scrive sullo
schermo quale file manca.
